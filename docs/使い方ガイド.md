# 候補者情報取り込みアプリ — 使い方ガイド（初心者向け）

このガイドでは、**作業1・作業2・作業3** を、パソコンやプログラミングの知識がなくてもわかるように説明します。

---

## このアプリでできること（イメージ）

- **入れるもの**: 履歴書のPDF、面談メモ（テキスト）、フラグのExcel の「どれか1つ以上」
- **出てくるもの**: 転職支援の業務で使う「共通の整理データ」と、FileMaker に取り込む用の **Excelファイル**
- **流れ**: ファイルを画面に置く → 「実行」を1回押す → しばらく待つ → Excel をダウンロードする

---

## 作業1: アプリを「用意する」（初回だけ）

アプリを動かすために、**最初に1回だけ** 次のことをします。

### 1-1. フォルダを開く

- このアプリのフォルダ（`candidate-intake` という名前のフォルダ）を開いてください。
- 中に `package.json` というファイルがある場所が、アプリの「根っこ」です。

### 1-2. コマンドを打つ（2つ）

パソコンに「ターミナル」や「コマンドプロンプト」「PowerShell」という画面があります。  
その画面で、**アプリのフォルダに移動して**、次の2つを **順番に** 実行します。

| 順番 | 打つ内容 | 意味（ざっくり） |
|------|----------|------------------|
| ① | `npm install` | アプリが動くために必要な部品をパソコンに取り寄せる |
| ② | `npm run dev` | アプリの「開発用サーバー」を起動する |

②を実行すると、画面に **「Local: http://localhost:3000」** のような表示が出ます。  
ここまで出ていれば「用意」は完了です。**この画面は閉れないように**してください（閉じるとアプリが止まります）。

### 1-3. ブラウザで開く

- インターネット用のブラウザ（Chrome や Edge など）を開く
- アドレス欄に **`http://localhost:3000`** と入力して Enter
- 候補者情報取り込みの画面が表示されれば、**作業1は完了**です。

---

## 作業2: 「APIキー」を設定する（初回だけ）

このアプリは、Google の「Gemini」というAIを使ってデータを整理します。  
そのために **「APIキー」** という「合言葉」を、アプリに教えておく必要があります。

### 2-1. APIキーを用意する

- あなた（または会社）が **Gemini の APIキー** を持っているか確認します。
- 持っていない場合は、Google の提供する手順に従ってキーを取得します（ここでは取得方法は省略します）。

### 2-2. 設定用ファイルを作る

- アプリのフォルダ（`candidate-intake`）の **中** に、次の名前のファイルを **新規で** 作ります。  
  **ファイル名（そのまま）**: `.env.local`
- 中身は **1行だけ** で、次のように書きます（`あなたのAPIキー` のところに、実際のキーを入れます）。

  ```
  GEMINI_API_KEY=あなたのAPIキー
  ```

- 保存したら、**作業2は完了**です。  
  ※ このファイルは秘密なので、人に送ったり GitHub に上げたりしないでください。

## 作業3: 実際に「使う」（毎回の流れ）

準備ができたら、**毎回** 次の手順で使います。

### 3-1. アプリを起動する

- 作業1と同じように、ターミナルでアプリのフォルダに移動し、**`npm run dev`** を実行します。
- ブラウザで **http://localhost:3000** を開き、候補者情報取り込みの画面を表示します。

### 3-2. ファイルを「置く」

画面上の **「1. ファイルをアップロード」** のところに、次の3種類のうち **少なくとも1つ** を置きます。

| 種類 | 説明 | ファイル例 |
|------|------|------------|
| 履歴書 PDF | 候補者の履歴書や登録シートのPDF | `resume.pdf` |
| 面談ログ | 面談のメモを書いたテキスト | `interview.txt` |
| フラグリスト | フラグや項目が書かれたExcel | `flags.xlsx` |

- **ドラッグ＆ドロップ**（ファイルを枠に引っ張って離す）でも、**「ファイルを選択」** ボタンで選んでもかまいません。
- 3つ全部でなくても、**1つだけ** でも動きます。

### 3-3. 「実行」を押す

- **「実行」** ボタンを **1回** クリックします。
- 画面に「① 共通解析中…」「② 質問JSON生成中…」「③ Excel生成中…」のように表示され、**順番に処理**されます。
- 数十秒〜1分ほど待つと、「③ Excel済」の横に **「ダウンロード」** ボタンが出ます。

### 3-4. Excel をダウンロードする

- **「ダウンロード」** ボタンをクリックすると、パソコンに **Excelファイル（.xlsx）** が保存されます。
- ファイル名は、候補者名などに応じて **「FileMaker用_〇〇.xlsx」** のようになります。
- このExcelには **「基本情報シート」** と **「職歴情報シート」** の2つのシートが入っており、FileMaker に取り込むための形式になっています。

ここまでできれば **作業3（1回分の利用）は完了**です。

## よくあること・注意

- **「共通解析エラー」などと出る場合**  
  - 作業2の APIキーが `.env.local` に正しく書かれているか確認してください。  
  - キーを直したら、ターミナルで `npm run dev` を一度止めて（Ctrl+C）、もう一度 `npm run dev` で起動し直します。
- **ファイルを何も置いていないのに「実行」を押した場合**  
  - 「PDF・面談ログ・フラグリストのいずれか1つ以上をアップロードしてください」と表示されます。1つ以上ファイルを置いてから再度「実行」してください。
- **質問リストの編集**  
  - 実行後、画面の下に「質問リスト（編集）」が出ます。ここで質問の文言や必須/任意、並び順を変えられます。必須ではありません。

## まとめ（1・2・3の対応）

| 作業 | 内容 | いつやるか |
|------|------|------------|
| **作業1** | アプリの用意（`npm install` → `npm run dev` → ブラウザで http://localhost:3000 を開く） | 初回・または新しいパソコンで使うとき |
| **作業2** | APIキーを `.env.local` に書く | 初回・またはキーを変えたとき |
| **作業3** | ファイルを置く → 「実行」→ ダウンロード | **毎回** 候補者ごとにExcelを作りたいとき |

この3つができれば、知識がなくても「ファイルを置いて実行してExcelを取る」まで一通りできます。
