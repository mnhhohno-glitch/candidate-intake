# Googleフォーム作成 — あなたがやること（手順だけ）

**知識がなくても大丈夫です。** 次の番号のとおりに、上から順にやってください。  
「フォーム作成でエラーになった」「Drive の権限を追加したい」ときに、**いまある GAS を最新の状態にする**ための手順です。

---

## 用意するもの

- 会社の **Google アカウント**でログインできること
- このアプリの **フォルダ**（または GitHub）で、下で出てくる **2つのファイル** を開けること
- すでに **Google Apps Script で「フォーム作成用」のプロジェクトを1つ作ったことがある**こと（まだの人は、先に「Googleフォーム作成_GASの入れ方_初心者向け.md」のステップ1〜4で初回設定をしてください）

---

## 手順1：プログラムのファイルを開いて、中身をすべてコピーする

1. このアプリのフォルダで、**`scripts`** というフォルダを開く。
2. その中の **`gas`** を開く。
3. **`CreateGoogleFormFromQuestionText.js`** というファイルをクリックして開く。
4. 開いた中身の **文字をすべて選択**する（Ctrl+A または Cmd+A）。
5. **コピー**する（Ctrl+C または Cmd+C）。  
   → この「コピーした内容」を、あとで Google の Code.gs に貼り付けます。

---

## 手順2：権限の設定ファイルを開いて、中身をすべてコピーする

1. 同じ **`scripts` → `gas`** のなかにある **`appsscript.json`** というファイルをクリックして開く。
2. 中身の **文字をすべて選択**して **コピー**する。  
   → この「コピーした内容」を、あとで Google の appsscript.json に貼り付けます。

**中身がわからないとき用（そのまま写して使ってください）：**

```
{"timeZone":"Asia/Tokyo","exceptionLogging":"STACKDRIVER","oauthScopes":["https://www.googleapis.com/auth/forms","https://www.googleapis.com/auth/spreadsheets","https://www.googleapis.com/auth/drive"]}
```

※ 上の1行全体をコピーして、Google の appsscript.json の中身と **ぜんぶ置き換え**ます。

---

## 手順3：Google Apps Script の画面を開く

1. ブラウザのアドレス欄に **https://script.google.com/** と入力して Enter を押す。
2. **会社の Google アカウント**でログインする（求められたら）。
3. **フォーム作成用のプロジェクト**（いままで使っているもの）をクリックして開く。  
   → 編集画面（Code.gs が真ん中に表示されている画面）になればOKです。

---

## 手順4：Code.gs を、手順1でコピーした内容で置き換える

1. 左のファイル一覧で **`Code.gs`** をクリックする（すでに開いている場合はそのままでよい）。
2. 右側の **白い編集エリア** をクリックする。
3. **いま表示されている文字をすべて選択**する（Ctrl+A または Cmd+A）。
4. **Delete キー**で削除する。
5. **手順1でコピーした「CreateGoogleFormFromQuestionText.js の内容」を貼り付ける**（Ctrl+V または Cmd+V）。
6. **保存**する（Ctrl+S または、画面上の「保存」アイコン／「保存」ボタンを押す）。

---

## 手順5：appsscript.json を表示して、手順2でコピーした内容で置き換える

1. 左のサイドバーで **歯車アイコン**（「プロジェクトの設定」）をクリックする。
2. 設定画面で、**「appsscript.json マニフェストファイルをエディタで表示する」** の **チェックを入れる**。
3. 左の **ファイル一覧**（〈〉のようなアイコンが「エディタ」の一覧）に戻る。
4. **`appsscript.json`** という名前のファイルが増えているので、それを **クリックして開く**。
5. 右側に表示された **中身をすべて選択**して削除する。
6. **手順2でコピーした「appsscript.json の内容」を貼り付ける**。
7. **保存**する。

※ これで「Drive の権限」が追加されます。作成したフォームを自動で「リンクを知っている全員」に共有するために必要です。

---

## 手順6：デプロイを「新バージョン」でやり直す

1. 画面上部（または右側）の **「デプロイ」** をクリックする。
2. **「デプロイを管理」** をクリックする。
3. 一覧に **「ウェブアプリ」** という種類のデプロイがあるので、その行の **鉛筆アイコン（編集）** をクリックする。
4. **「バージョン」** のところで **「新バージョン」** を選ぶ（プルダウンで選べます）。
5. **「デプロイ」** ボタンを押す。
6. **「アプリにアクセスを許可しますか？」** や **「Drive へのアクセスを許可しますか？」** のような画面が出たら、**「許可」** または **「アクセスを許可」** を選んで進める。
7. 完了すると、**「ウェブアプリの URL」** が表示されます。  
   → URL は前と同じことが多いです。変わっていないなら、**Railway の設定はそのままで大丈夫**です。変わっていたら、次の手順7でその新しい URL を Railway に貼り直してください。

---

## 手順7：アプリ（Railway）に URL を教えているか確認する

1. **Railway** のサイト（https://railway.app など）を開き、このプロジェクト（candidate-intake）を開く。
2. **「Variables」**（環境変数）の画面を開く。
3. **変数名** が **`GAS_WEB_APP_URL`** の行を探す。
4. **値** に、手順6で表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec` のような長いもの）が入っているか確認する。  
   - 入っていて、手順6のあとで URL が **変わっていない** → 何もしなくてOK。  
   - 入っていない、または手順6で **URL が変わった** → 値の欄に、その URL を貼り付けて保存する。
5. Railway の **再デプロイ**（Deployments から「Redeploy」など）をすると、設定が確実に反映されます。

---

## ここまでできたら

- **Candidate Intake の画面**で「Googleフォームを作成」を押すと、フォームが作られるはずです。
- **「フォームは作成されましたが、共有設定が…」** という**黄色い警告**だけ出る場合は、Drive の許可がまだ出ていない可能性があります。  
  → 手順6をもう一度やり、**「Drive へのアクセスを許可しますか？」** が出たときに **「許可」** を選んでください。
- **すでに作ったフォーム**がスマホで開けない場合は、「Googleフォーム作成_GASの入れ方_初心者向け.md」の **「スマホでアクセス権が必要…」** のところに書いてあるとおり、そのフォームの **「公開」→「管理」** で「リンクを知っている全員」に変更してください。

---

## 困ったとき

| こんなとき | どうするか |
|------------|------------|
| 「Code.gs が見つからない」 | 左のファイル一覧の一番上あたりにある **Code.gs** をクリックする。 |
| 「appsscript.json が表示されない」 | 手順5の「歯車」→「appsscript.json マニフェスト…」の **チェックを入れたか** もう一度確認する。チェックを入れると、左の一覧に appsscript.json が現れる。 |
| 「デプロイを管理」の画面がわからない | 画面上部の **「デプロイ」** を押したあと、出てきたメニューから **「デプロイを管理」** を選ぶ。 |
| 「新バージョン」が選べない | 「デプロイを管理」で **鉛筆アイコン（編集）** を押したあと、**「バージョン」** の右にあるプルダウンを開き、**「新バージョン」** を選ぶ。 |
| URL をどこに貼るかわからない | Railway の **Variables** で、**変数名** を `GAS_WEB_APP_URL`、**値** にコピーした URL を貼る。 |

---

この手順は、**「Code.gs と appsscript.json を最新の内容に更新 → デプロイを新バージョンでやり直す → 必要なら Railway の URL を確認」** を、番号のとおりにやるためのものです。
