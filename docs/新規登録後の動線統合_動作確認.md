# 新規登録後の動線統合 — 動作確認手順

## 変更概要

- **登録完了後**: トップに戻らず、求職者詳細（ファイルD&D画面）へ直接遷移
- **ファイル取り込み**: 1回のD&Dで「出力開始」を押すと Excel と 質問文・Googleフォーム が同時に生成される（既存の records/[candidateId] の一気通貫フローを利用）
- **旧フロー廃止**: 登録直後の「Excel専用D&D画面」は削除済み（/register は登録フォームのみ）

## 確認手順

1. **新規登録直後に詳細画面へ遷移**
   - トップ → 「新規求職者作成」→ 求職者番号・氏名・CAを入力 → 「作成する」
   - → 登録成功後、`/records/{求職者番号}` にリダイレクトされること
   - → トップを経由していないこと

2. **1回のD&DでExcelとGoogleフォームが生成**
   - 上記で遷移した画面で「アップロード」を選択
   - PDF・面談ログ・フラグのいずれか以上 + 実績ヒアリングの職種カテゴリを選択
   - 「出力開始」を1回押す
   - → 「出力結果」タブに Excel DL・質問文・GoogleフォームURL が表示されること

3. **二重実行の抑止**
   - 登録時:「作成する」押下中はボタンが「登録中…」になり無効化されること
   - 出力時: 処理中は「出力開始」が押せず、アップロードも無効化されること（既存仕様）

4. **旧フローが到達不能**
   - /register で登録後、Excel専用のD&D画面（登録済み＋出力開始のみの画面）が表示されないこと

## 既存動線の確認

- トップ → 一覧から既存求職者を選択 → 詳細画面 → アップロード → 出力開始 → Excel・質問文・フォーム同時生成が従来どおり動作すること
