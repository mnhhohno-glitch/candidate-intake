# 質問文生成 422 / 400 エラー — Railway ログ分析と原因

## 400「PDFからテキストを抽出できませんでした」について

**スキャンではない PDF でも 400 になる理由**

- 400 は「**サーバー側で PDF から 1 文字も取れなかった**」ときに返しています（抽出結果が 0 文字）。
- スキャン画像でなくても、次のような場合に 0 文字になることがあります。
  - **pdf-parse** がその PDF の形式・バージョン・フォント埋め込みに対応していない
  - パスワード保護・制限付き PDF
  - サーバー環境（Node / メモリ）の制約で例外が発生し、`extractTextFromPdf` が空文字を返した
  - テキストレイヤーが 0 で OCR フォールバックも 0 文字（前回ログでは 38 文字だったが、環境や PDF 次第で 0 の可能性あり）

**対処の目安**

- 「テキストが選択・コピーできる」形式の PDF で再度お試しください。
- 別のアプリで同じ PDF を「名前を付けて保存」し直してからアップロードすると通ることがあります。
- それでも 400 の場合は、サーバーログで `[extractText]` や `[hearing-question-text] PDF extraction returned 0` を確認すると原因の切り分けになります。

## 422 エラー — Railway ログ分析

## ログから分かったこと

該当ログ（東 裕太郎さん PDF アップロード時）では次のように記録されていました。

| 段階 | 内容 |
|------|------|
| **PDF テキストレイヤー** | `buffer=7720 bytes, pages=3, extracted=0 chars` → **0 文字** |
| **OCR フォールバック** | 実行され、`OCR done, pages: 3 chars: 38` → **38 文字のみ** |
| **フォント/CMap 警告** | `Ensure that the cMapUrl and cMapPacked API parameters are provided` |
| **ゲート** | `gate_checks_failed reason= resumePdfChars=38 < 101` → **422 返却** |

## 原因の整理

1. **テキストレイヤーが 0 文字**
   - この PDF は画像ベース（スキャン）か、テキストが埋め込まれていない形式の可能性が高いです。
   - そのため `pdf-parse` では 1 文字も取れていません。

2. **OCR が 38 文字しか取れていない**
   - 3 ページあるのに 38 文字だけということは、**描画時にフォント/CMap の不足**で日本語が正しく描画されておらず、OCR がほとんど読めていない可能性があります。
   - ログの `cMapUrl and cMapPacked API parameters are provided` は、日本語等のフォント用 CMap が未指定だったことを示しています。

3. **ゲートの判定**
   - 抽出結果が **38 文字** のため、「101 字以上で通過」のゲートで **正しく NG** となり、422 が返っています。
   - ゲートの閾値が悪いのではなく、「サーバー上で実際に取れた文字数が 38 だった」ことが原因です。

## 実施した対応

- **OCR 時の cMap / standardFontDataUrl を指定**
  - `extractTextPdfOcr.ts` で、`pdfjs-dist` の `getDocument` に  
    `cMapUrl`・`cMapPacked`・`standardFontDataUrl` を渡すように変更しました。
  - Railway 上でも日本語が正しく描画され、OCR で取れる文字数が増える可能性があります。

## 運用上の注意

- **テキストレイヤー付きの PDF を推奨**
  - スキャンではなく、パソコンで作成・保存した「テキスト付き」の PDF だと、テキスト抽出で多くの文字が取れ、ゲートも通りやすくなります。
- **422 が出た場合**
  - レスポンスの `detail` に「抽出文字数: ○○ 文字」が入るようになっています。  
    - 38 のように少ない → 抽出/OCR 環境の制約が疑われます。  
    - 上記 cMap 対応のデプロイ後、同じ PDF で再試行してみてください。
