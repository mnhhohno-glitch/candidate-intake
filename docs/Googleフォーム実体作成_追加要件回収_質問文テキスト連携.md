# Candidate Intake：質問文テキスト連携型 Googleフォーム実体作成 — 追加要件回収

**前提**: 既存の「候補者に送る質問文（テキスト）」生成フローは**一切変更しない**。テキスト出力を維持しつつ、**同じ生成結果（candidate_question_text_only）**からGoogleフォーム実体も作成し、フォームURLを生成・表示（必要なら保存）する追加機能の要件を回収する。

---

## 1. 絶対要件サマリ（変更禁止）

| 項目 | 内容 |
|------|------|
| テキスト出力の維持 | 既存の質問文テキスト生成（`POST /api/intake/hearing-question-text`）の内部処理（ゲート、Step A/B、自己検査、再試行、06組み込み）を**変更しない**。テキストは従来通り表示・コピー可能であること。 |
| 追加であること | テキストを削除/置換せず、**追加で**Googleフォーム作成機能を実装する。 |
| 対象外 | Excel（03）・共通解析（01）・質問定義JSON（02）とは関連付けない。今回の変更対象外。 |
| 文言の改変禁止 | 生成されたテキスト質問文の文言・改行・順序・記入例などを勝手に簡素化・言い換えしない。 |
| フォーム作成の入力 | フォーム作成の入力は **candidate_question_text_only**（同一生成結果）。PDF内容により変わる動的生成仕様を崩さない。 |

| 実装方針 | Googleフォーム作成はApps Script（GAS）前提。フォーム所有は会社Workspaceアカウント（個人アカウントは使わない）。 |

## 3. 現行システムの前提（変更しない部分）

- **エンドポイント**: `POST /api/intake/hearing-question-text`
- **入力**: job_type, achievement_category, pdf, interviewLog（任意）, candidate_name（任意）
- **出力**: candidate_question_text_only（候補者に送る質問本文のみ。見出し・内部メモ・URLは含めない）
- **ゲート**: PDF抽出テキストが一定文字数未満の場合は422で停止（Step A/Bは実行しない）
- **パイプライン**: Step A（05_structured_extract）→ Step B（04 + 06_achievement_category_followup）
- **保存**: 質問文テキストはサーバーに保存せず、画面で表示・コピーのみ（現状維持可）
- **UI**: 質問文生成ボタンでテキストを表示、コピーでクリップボードにコピー（維持）
