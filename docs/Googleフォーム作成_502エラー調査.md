# Googleフォーム作成で 502 エラーが出る場合の調査手順

「Googleフォームを作成」を押したときに **502** や **「GASの応答形式を確認してください」** と表示される場合の原因と確認方法です。

---

## 想定される原因

1. **GAS が JSON 以外を返している**  
   フォーム作成中に GAS 側で例外が発生すると、Google が HTML のエラーページを返すことがあります。Next.js は JSON を期待しているため、パースに失敗して 502 を返します。

2. **GAS の URL やデプロイのずれ**  
   - Railway の環境変数 `GAS_WEB_APP_URL` が、**「デプロイ」→「ウェブアプリ」で取得した URL（/exec で終わるもの）** と一致しているか確認してください。  
   - `/dev` の URL は開発用のため本番では使わず、**必ず「新しいデプロイ」で「ウェブアプリ」を選んで取得した URL** を設定してください。

3. **GAS の実行制限・権限**  
   - フォーム・スプレッドシートは GAS を実行している **Google アカウント（Workspace）** で作成されます。  
   - そのアカウントの Drive/Forms の容量や、組織のポリシーでフォーム作成が制限されていないか確認してください。

4. **タイムアウト**  
   - 質問文が極端に長い場合、GAS の実行が 90 秒を超えると Next.js 側でタイムアウトし 502 になります。  
   - エラーメッセージに「タイムアウト」と出ている場合は、質問文の長さや GAS の処理を確認してください。

---

## 確認手順

### 1. 本番ログで GAS の応答を確認する

Railway の **Deployments** → 該当デプロイ → **View Logs** で、次のログを探します。

- **`[create-google-form] GAS response not JSON. status=XXX body=...`**  
  → GAS が HTML やエラーページを返している場合。`body=` の続きに GAS のエラー本文や HTML の断片が出ます。  
  → **GAS の Code.gs を最新版（例外時も JSON で返す版）に更新し、再度「デプロイを管理」から「新バージョン」でデプロイ**すると、次回からは GAS の例外メッセージが JSON で返り、画面上にも表示されます。

- **`[create-google-form] GAS fetch failed: ...`**  
  → GAS の URL に到達できていません。`GAS_WEB_APP_URL` の値とネットワーク（ファイアウォール等）を確認してください。

- **`[create-google-form] GAS error: ...`**  
  → GAS は JSON で返しているが、`error` フィールドがあるか HTTP が 4xx/5xx。ログの内容がそのまま GAS からのエラーです。

### 2. GAS 側の実行ログを確認する

1. [Google Apps Script](https://script.google.com/) で該当プロジェクトを開く。  
2. フォーム作成を再度実行したあと、**「実行数」** または **「マイ実行」** で直近の実行を開く。  
3. **「ログ」** や **「エラー」** に例外メッセージが出ていないか確認する。  
4. エラーがある場合、その内容に合わせて Code.gs の処理や権限（Drive / Forms の利用許可）を見直す。

### 3. GAS を「例外時も JSON で返す」版に更新する

`scripts/gas/CreateGoogleFormFromQuestionText.js` の **最新版** を Code.gs にコピーし、**「デプロイ」→「デプロイを管理」→ ウェブアプリの「編集」→「新バージョン」で「デプロイ」** してください。  
これにより、フォーム作成中の例外が発生しても GAS が HTML ではなく JSON `{ "error": "フォーム作成中にエラーが発生しました: ..." }` を返すようになり、画面上に具体的なエラー内容が表示されます。

---

## まとめ

| 画面のメッセージ | まず確認すること |
|------------------|------------------|
| GASの応答形式を確認してください | Railway ログの `[create-google-form] GAS response not JSON` を確認。GAS を「例外時も JSON 返却」版に更新。 |
| タイムアウトしました | 質問文の長さ・GAS の処理時間を確認。 |
| GASへの接続に失敗しました | `GAS_WEB_APP_URL` の値、GAS の「ウェブアプリ」デプロイ URL（/exec）であること。 |
| 認証トークンが無効です | GAS のスクリプトプロパティ `INVOKE_TOKEN` と Railway の `GAS_INVOKE_TOKEN` が一致しているか。 |
| フォーム作成中にエラーが発生しました: ... | 表示された例外メッセージに従い、GAS の権限・コード・入力データを確認。 |
