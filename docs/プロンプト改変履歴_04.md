# 04 質問文プロンプトの改変履歴（簡素化なし）

**base_prompt の既存本文は削除・要約・再構成していません。追加・追記のみです。**

## 追加・追記した箇所のみ

1. **絶対に守る前提条件**  
   - 追加: 「PDFおよび面談メモを**最初から最後まで必ず読み切ってから**質問を生成すること。先頭のみの参照・要約・飛ばし読みは禁止。読み取りに時間をかけても正確さを優先すること。」

2. **グローバル出力ルール**  
   - 追加: 「**【重要】該当する全てのブロックを省略せず、最後まで必ず出力すること。** 途中で打ち切る・要約する・1ブロックで終了することは禁止。出力順の1〜8のうち該当するものはすべて、各ブロック末尾を「回答：」で区切って出力すること。」

3. **住所確認を出さない条件**  
   - 既存の「番地・建物名・部屋番号がすべて揃っている場合は～」を拡張し、事前抽出の3フラグが true のときは絶対に住所確認を出さないこと、PDFの住所欄に建物名・部屋番号が両方あれば出さないことを明記。

4. **証明写真データ（固定）**  
   - テンプレート末尾に「回答：」を追加（他ブロックと統一。GAS の「回答：」分割で欠落しないようにするため）。

## 変更していないもの

- 出力順（1〜8）、必須固定確認（高校・資格・住所）、職務経歴ルール、**実績確認は achievement_category 指定時は「追加実績ヒアリングロジック」の該当カテゴリをそのまま追加すること**（04 行203）、部署・役職、意識・自己PR・証明写真のテンプレート本文、学歴ガードレール、最終出力ルール、input_instruction の文言はすべて**手を加えていません**。
- 06_achievement_category_followup.yaml は未変更。事務・サポート職・営業・専門・マネジメントの各 questions はそのままです。

## loadSpec での組み立て

- base_prompt はそのまま使用。  
- achievement_category 指定時は 06 の該当カテゴリを「## ■ 追加実績ヒアリングロジック」として**末尾に結合**しているだけ（従来どおり）。  
- 今回の修正で、userPrompt に「【必須】achievement_category が指定されているため、～該当カテゴリの質問を省略せず全て出力すること。」を**1行追加**したのみ。
