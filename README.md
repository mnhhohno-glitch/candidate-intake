# 候補者情報取り込み（Candidate Intake）

PDF・面談ログ・フラグリストから共通解析JSONを生成し、Googleフォーム質問定義とFileMaker用Excel（.xlsx）を一気通貫で出力するアプリです。

- **今すぐやること（ターミナル不要）**: [docs/次のアクション_Railwayでサーバーを上げる.md](docs/次のアクション_Railwayでサーバーを上げる.md) — ブラウザだけの操作で、番号どおりに進められます。
- **GitHub と Railway の全体手順**: [docs/デプロイ手順_GitHubとRailway.md](docs/デプロイ手順_GitHubとRailway.md)

## 起動方法

```bash
# 依存関係インストール
npm install

# 開発サーバー起動（http://localhost:3000）
npm run dev
```

本番ビルド・起動:

```bash
npm run build
npm start
```

## 環境変数

| 変数名 | 説明 | 必須 |
|--------|------|------|
| `GEMINI_API_KEY` | Google Gemini API キー | はい |

**ユーザー作業**: `.env.local` に以下を設定してください（リポジトリにコミットされません）。

```
GEMINI_API_KEY=あなたのAPIキー
```

## 入力ファイル形式

- **PDF**: 履歴書・登録シート（テキスト抽出して送信）
- **テキスト（.txt）**: 面談メモ・面談ログ
- **Excel（.xlsx）**: フラグリスト（列名と値の対応）

アップロードは画面上のドラッグ&ドロップで行います。いずれか1つ以上を投入後、「実行」で ①共通解析 → ②質問JSON生成 → ③Excel出力 を順に実行します。

## 運用フロー

1. ブラウザで http://localhost:3000 を開く
2. PDF / 面談ログテキスト / フラグリストxlsx をドラッグ&ドロップでアップロード
3. 「実行」ボタンをクリック
4. ① 共通解析JSON（common_analysis_json）が生成される
5. ② 質問定義JSONが生成され、プレビューで編集可能（任意）
6. ③ FileMaker用Excel（基本情報シート・職歴情報シート）が生成される
7. 画面からExcelをダウンロード（1ファイルに「基本情報シート」「職歴情報シート」の2シートを含む `FileMaker用_氏名.xlsx`）

## フォルダ構成

```
│   ├── app/                   # Next.js ページ・API
│   ├── components/            # UI（UploadPanel, ResultPanel, PreviewEditor）
│   ├── services/              # Gemini呼び出し・Excel生成

```

## 仕様

- ① 共通解析: `specs/01_common_analysis_prompt.yaml` に従い、PDF/面談/フラグから common_analysis_json を生成
- ② 質問生成: `specs/02_google_form_prompt.yaml` に従い、common_analysis_json のみを入力に質問JSONを生成
- ③ Excel出力: `specs/03_filemaker_excel_prompt.yaml` に従い、common_analysis_json のみを入力に excel_files JSON を生成し、.xlsx に変換

既存のYAMLプロンプトは改変せず、差分が必要な場合は新規ファイルで管理してください。

## ネクストアクション（次にやること）— 知識がなくてもできる手順

「何をすればいいかわからない」という方向けに、**やる順番**だけまとめています。用語の意味がわからなくても、番号のとおりに進めれば大丈夫です。

### 前提：アプリを1回起動できる状態にする

1. **このフォルダを開いた状態で、ターミナル（黒い画面）を開く**  
   - Cursor や VSCode なら、メニューから「ターミナル」→「新しいターミナル」でOK。
2. **次の2つを打ち込んで Enter を押す**
   - `npm install`  
     → しばらく待つ。終わったら次へ。
   - `npm run dev`  
     → 「Local: http://localhost:3000」のような表示が出たら起動できています。
3. **ブラウザで http://localhost:3000 を開く**  
   - 候補者情報取り込みの画面が出ればOK。

ここまでできたら、下の「普段やること」に進めます。

---

### 普段やること（ファイルを入れてExcelを出す）

| 順番 | やること | 補足 |
|------|----------|------|
| 1 | 画面の「1. ファイルをアップロード」のところに、**履歴書PDF・面談メモ（.txt）・フラグリスト（.xlsx）** のうち、持っているものをドラッグ＆ドロップする | 3つ全部でなくても、1つ以上あればOK。 |
| 2 | **「実行」ボタン** を押す | 数十秒かかることがあります。 |
| 3 | 「2. 結果」に **「① 共通解析済」「② 質問JSON済」「③ Excel済」** と出るまで待つ | エラー（赤いメッセージ）が出たら、下の「トラブルのとき」を見る。 |
| 4 | **「ダウンロード」ボタン** を押して、出てきた Excel を保存する | ファイル名は「基本情報シート_（氏名）.xlsx」のようになります。 |

これが「次にやること」の基本の流れです。**ファイルを入れる → 実行 → Excel をダウンロード** だけ覚えれば大丈夫です。

---

### 画面に「PDF 0文字」と出たとき（リストやExcelの内容が足りないと感じるとき）

- **意味**  
  アプリが「履歴書PDFから文字を読み取れなかった」という状態です。  
  そのため、履歴書の内容（学歴・職歴の細かい部分など）が Excel にあまり反映されません。
- **次にやること**
  1. 使っている **履歴書のPDF** を、**パソコンで開いて、マウスで文字を選択できるか** 確認する。  
     - 選択できる → そのPDFのまま、もう一度「実行」してみる。  
     - 選択できない（画像だけのPDF） → 次の2のどちらかをする。
  2. **対処法（どちらかでOK）**  
     - **A.** 履歴書を **Word やブラウザで作成し直し、「PDFとして保存」** したものを使う。  
     - **B.** 今のPDFのまま使う場合は、「面談メモ」と「フラグリスト」の情報だけで Excel が作られる、と理解しておく（履歴書の内容は手で後からExcelに書き足す想定）。

---

### トラブルのとき（エラーや起動できない）

| 症状 | 次にやること |
|------|----------------|
| 「Port in use」「ポートが使われている」と出る | すでに同じアプリが別のターミナルで動いている可能性があります。他のターミナルを閉じるか、パソコンを一度再起動してから、もう一度 `npm run dev` を実行してみてください。 |
| 「GEMINI_API_KEY」や「APIキー」のエラー | このプロジェクトのフォルダにある **`.env.local`** というファイルを開き、中に `GEMINI_API_KEY=（あなたのキー）》` の1行が入っているか確認してください。入っていなければ、正しいAPIキーを `=` の後ろに書いて保存し、もう一度「実行」してみてください。 |
| 実行したら赤いメッセージが出る | 画面に表示されているエラー文をそのままコピーして、サポートの人や開発者に伝えると原因を特定しやすいです。あわせて「どのファイルをアップロードしたか」「PDFのファイル名」も伝えるとよいです。 |

---

### 用語が気になったとき（知らなくても操作はできる）

- **共通解析** … アップロードした3種類のファイルを、AIが読んで「1つの中間データ」にまとめる処理です。ここが終わると「① 共通解析済」と出ます。
- **質問JSON** … 共通解析で「書かれていなかった項目」を、あとから聞くための質問リストです。画面では「② 質問JSON済」と出ます。普段は触らなくて大丈夫です。
- **Excel出力** … 共通解析の結果から、FileMaker用の「基本情報シート」「職歴情報シート」を作る処理です。「③ Excel済」の横の「ダウンロード」で、そのExcelを保存できます。

**まとめ**：とにかく **「ファイルを入れる → 実行 → ダウンロード」** の3ステップが、あなたの「ネクストアクション」です。
