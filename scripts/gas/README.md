# Googleフォーム作成用 Apps Script（GAS）

質問文テキスト（`candidate_question_text_only`）から Google フォームの実体を作成するスクリプトです。会社の Google Workspace アカウントで所有・実行してください。

## セットアップ

1. [Google Apps Script](https://script.google.com/) を開き、会社アカウントでログインする。
2. 「新しいプロジェクト」で空のプロジェクトを作成する。
3. `CreateGoogleFormFromQuestionText.js` の内容をコピーし、GAS エディタの `Code.gs` を置き換える（または新規ファイルとして追加する）。
4. **Drive 権限（フォームを「リンクを知っている全員」で共有するために必須）**  
   - 左の「プロジェクトの設定」（歯車アイコン）を開く → **「appsscript.json」マニフェストファイルをエディタで表示する** にチェックを入れる。  
   - 左のファイル一覧に `appsscript.json` が表示されるので開き、`scripts/gas/appsscript.json` の内容（`oauthScopes` に `https://www.googleapis.com/auth/drive` を含む）で置き換える。保存する。  
   - 未設定のままデプロイすると、フォーム作成は成功するが共有だけ失敗し、画面上に警告が出ます。その場合は作成されたフォームを手動で「公開」→「管理」から「リンクを知っている全員」に変更するか、上記の通り appsscript.json を設定して**再デプロイ**し、表示される認証画面で Drive へのアクセスを許可してください。
6. （任意）認証トークンを使う場合:
   - エディタで「プロジェクトの設定」→「スクリプト プロパティ」を開く。
   - プロパティを追加: 名前 `INVOKE_TOKEN`、値にランダムな文字列（例: UUID）を設定。
   - Next.js の `.env.local` に同じ値を `GAS_INVOKE_TOKEN` で設定する。
7. 「デプロイ」→「新しいデプロイ」→ 種類で「ウェブアプリ」を選択。
   - 説明: 任意（例: Candidate Intake フォーム作成）
   - 実行ユーザー: **自分**
   - アクセス: **全員**（トークンで制限する場合）または「組織内」
8. 「デプロイ」をクリックし、表示される **ウェブアプリの URL** をコピーする。
9. Next.js の `.env.local` に `GAS_WEB_APP_URL=https://script.google.com/...` を設定する。

## 動作

- Next.js から `POST` で JSON `{ candidateId, candidateName?, questionText, token? }` を送信する。
- テキストを「回答：」で区切り、ブロックごとに以下で作成する。
  - **タイトル**: 求職者NOは表示せず、氏名に「様」を付与（例: 原 直希様_質問フォーム）。
  - **実績**を含むブロック: 段落テキスト＋注釈「※不明な場合は空白で構いません」。
  - **仕事において意識していたこと／自己PR**: ブロック内の「1. 〇〇」「2. 〇〇」を検出してチェックボックス（複数選択可）。
  - **写真データの提出**: ラジオボタン（3択: 別途提出／証明写真機で撮影後提出／スマホ撮影後提出）。
  - **資格**: 1行1質問＋「その他（追加の資格）」に注釈「他に追加で記載する資格がある場合は資格名：取得年月を追加記入してください」。
  - 上記以外: 段落テキスト。
- 末尾に個人情報同意: 説明「※内容を確認する場合のみ以下をご覧ください…」→ ポリシー全文 → 同意チェック（必須）。チェックのみで送信可。
- 回答先スプレッドシートを自動作成して紐付ける。
- フォームを **「リンクを知っている全員が閲覧可能」** に共有する（Drive 権限がない場合は共有に失敗し、`shareWarning` 付きで URL のみ返す。その場合は手動共有または appsscript.json で Drive スコープを追加して再認証）。
- レスポンスで `formId`, `responseUrl`, `editUrl` を返す。共有失敗時は `shareWarning` も返す。

## 注意

- プライバシーポリシー本文は要件どおり改変していません。変更が必要な場合はスクリプト内の `PRIVACY_POLICY_BODY` を編集してください。
- 同意チェックのラベルは固定です: 「上記『求職者向け個人情報の取扱いについて』を確認し、同意します。」
